# 거래소 전체 섹터 검색 · 주도주 후보 · ETF · 기관 데이터

## 사용자 요청과 성공 기준

현재 설정된 소수 후보 대신 한국·미국·일본·대만·홍콩·싱가포르 거래소 전체 상장 주식에서 섹터를 검색하고 가치평가한다. 다음 주도 섹터와 주도주 후보를 좁히는 근거를 보여준다. 이전에 후속 단계로 둔 ETF와 기관 데이터는 이번 구현 범위에 포함한다. 내부자 거래·공매도·포트폴리오 최적화는 이번 변경에 포함하지 않는다.

검색은 한글·영문 섹터명 및 테마명(AI, 반도체 등)을 지원한다. 결과마다 종목명·시장·섹터·관련 근거·분류 출처·분류 시점을 표시한다. 조회 결과와 가치평가 실행을 연결하며 계산 상태, 점수, 안전마진, 보류 사유를 보여준다. 전 종목 목록의 확보와 전 종목 테마 분류 완료를 같은 것으로 취급하지 않는다.

## 접근법

1. 기존 테마 후보 확대: 간단하지만 거래소 전체 요청을 충족하지 못해 선택하지 않는다.
2. 거래소 전체 목록 + 별도 분류 + 비동기 평가: 선택한다. 목록과 분류의 커버리지를 보여주고 현재 평가 엔진을 재사용한다.
3. 외부 통합 데이터 서비스: 국가별 분류·ETF·기관 데이터의 공백을 채우는 선택적 연결로 지원한다. 유료 계약이나 구독을 자동으로 만들지 않는다.

## 국가별 목록과 분류

각 시장에 독립 수집기를 둔다. 한국 KRX, 미국 Nasdaq Trader의 Nasdaq/기타 거래소 목록, 일본 JPX, 대만 TWSE/TPEx, 홍콩 HKEX, 싱가포르 SGX를 우선 확인한다. 각 어댑터는 정상 수집, 부분 수집, 설정 필요, 오류를 구별한다. 해당 공급자의 이용 조건·공개 경로·필요 인증이 확인된 어댑터만 연결 완료로 표시한다.

보통주·우선주·ADR·REIT·ETF 등을 종목 유형으로 구분한다. 공식 업종과 AI 등 주제를 구분한다. 공식 업종, 회사 사업 설명, 검토된 다중 테마 연결을 분류 근거로 저장한다. 기업 이름의 단순 부분 일치만으로 AI 기업을 확정하지 않는다. 한글·영문 별칭과 키워드 사전을 제공한다. 미분류는 결과 커버리지에서 명시한다. 목록 갱신은 기존 자료를 먼저 지우지 않고 성공한 스냅샷에서 교체하며 신규·상장폐지 기록을 보존한다.

## 검색·가치평가 흐름

검색창, 국가 필터, 섹터/테마 구분, 검색 결과 개수·분류 커버리지, 페이지 이동을 제공한다. 선택 종목 또는 검색 결과 전체 평가를 비동기 작업으로 실행한다. 전체 결과 평가도 공급자 한도 내 작은 묶음으로 처리하고 진행률·완료·오류·취소를 기록한다. 검색 결과 전체를 상위 N개로 조용히 잘라 평가하지 않는다. 새로운 검색 평가가 기존 다른 종목·국가의 결과를 삭제하지 않도록 저장 경로를 변경한다.

ETF는 기업 FCFF DCF로 평가하지 않는다. ETF 상세는 구성 종목, 운용보수, 규모, 유동성, 추적 정보와 자금 흐름으로 구성하며 확보되지 않은 항목은 결측으로 둔다. 보통주 외 종목은 기존 전용 모형 보류 정책을 적용한다.

## 주도주·섹터 후보 근거

가치평가 점수와 별도의 '관찰 후보 점수'를 제공한다. 미래 수익률 예측 확률이나 확정 매수 신호라고 표시하지 않는다.

- 수요·수주: 공시에서 확인 가능한 수주잔고·계약·매출 자료. 비정형 자료는 검토 근거가 없으면 점수화하지 않는다.
- 실적: 같은 기준의 매출·이익률·현금흐름 추세. 전망치 상향은 전망 데이터 공급자가 있을 때만 사용한다.
- 상대강도: 해당 시장 기준지수 대비 3/6/12개월 배당·분할 조정 수익률. 가격 기간이 부족하면 제외한다.
- 확산: 섹터 구성 종목의 상대강세 비율, 유동성·거래대금 변화. 전체 커버리지와 표본 수를 표시한다.
- 가치: 기존 안전마진과 역산 DCF의 내재 성장률을 함께 표시한다.
- ETF·기관: 기간과 출처를 확인한 데이터만 보조 근거로 연결한다.

결측은 중립 점수나 0원 흐름으로 채우지 않는다. 초기 점수는 기간·가중치·사용된 항목·커버리지를 공개하고 최소 자료가 없으면 점수를 보류한다. 국가 간 통화 금액이나 다른 기간의 기관 자료를 직접 합산하지 않는다. 과거 검증 전에는 점수의 예측력을 입증했다고 주장하지 않는다.

## ETF 자금 흐름

ETF 목록·테마 분류·관련 종목 연결을 저장한다. 거래대금, 투자자 순매수, 펀드 설정/환매를 별도 항목으로 표시한다. 가격 상승에 따른 AUM 증가는 자금 유입으로 취급하지 않는다. 실제 설정/환매 자료를 우선하며 NAV와 발행좌수 변화로 추정할 경우 추정 표시와 산식·시점·통화·분할/병합·분배금 처리 기준을 저장한다. 필요한 자료가 없으면 자금 흐름 미지원이다. 보유 구성은 기준일과 가중치를 저장한다.

## 기관 데이터

한국은 공개 투자자별 거래 자료에서 기관 순매수를 기간별로 수집한다. 실제 공급자가 제공한 투자자 구분을 보존한다. 미국은 SEC 13F의 관리자별 분기 보유와 주식 수 변화로 시작하며 거래일별 순매수라고 부르지 않는다. 가치 변화는 가격 변화에 영향을 받으므로 주식 수 변화와 구분한다. 수정 공시, 신규·청산, 옵션, 복수 관리자의 중복, 보고 시점과 분기 기준일을 처리한다. CUSIP→상장 종목 매핑이 확정되지 않으면 종목에 연결하지 않는다. 관리자 수·선택 기준을 표시해 표본을 미국 전체 기관으로 오해하지 않도록 한다.

다른 국가도 실제 확보 가능한 투자자 구분·보유 공시 자료에 따라 독립 어댑터를 두고 미연결 상태를 공개한다. SEC 연락처 식별자 등 필요한 설정을 기존 로컬 환경·GitHub Secrets/Variables 정책에 맞게 읽고 키를 로그에 남기지 않는다.

## 저장·API·작업

시장 목록 스냅샷, 종목 식별/유형, 분류 근거, 가격 시계열, ETF별 보유/흐름, 기관별 공시/거래, 계산 결과 및 작업 상태를 별도 저장한다. 수집 시점과 자료 기준일을 보존한다. 원천 자료 보존과 중복 방지, 변경 이력을 제공한다. 과거 조회는 공개 시점·첫 수집 시점 모두를 제한한다.

시장 갱신, 섹터 검색, 검색 평가 작업, 주도 후보 조회, ETF·기관 상세 API를 추가한다. 입력 검증·호출 제한·요청 타임아웃·재시도·캐시를 적용하고 사용자 입력을 URL이나 SQL에 직접 결합하지 않는다. 검색·평가 API에서 지원 여부와 부분 자료 상태를 반환한다.

## 검증·완료 기준

각 어댑터의 실제 출처 확인 및 연결 테스트, 공식 파일 샘플 기반 파싱 테스트, 신규·상장폐지·종목 유형·별칭·테마 다중 분류·미분류 커버리지 테스트를 수행한다. 검색 결과 전체 처리, 중복 작업, 타 시장 결과 보존, 결측·0 흐름 구분, ETF AUM 가격효과, 13F 수정·중복·시점 테스트를 포함한다. 상대강도는 기준지수와 기간이 맞는 고정 샘플로 계산 검증한다. UI에서 검색→선택/전체 평가→결과→근거 보기까지 확인한다.

모든 6개 시장이 데이터 공급 조건 없이 즉시 연결된다고 가정하지 않는다. 구현 코드 완료와 실데이터 연결 완료를 따로 보고하고, 실패한 연결을 완료로 표시하지 않는다. 이 명세 승인 후 구현 계획을 작성해 작업 순서와 연결 제약을 확정한다.
