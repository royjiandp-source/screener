# 한국·싱가포르·미국 시장 탐색

본문은 두 결과 표로 구성됩니다. **국가별 가치투자 집계와 미국 거시 참고 정보는 UI, API, 수집·경기 판단 로직에서 제거했습니다.** 시장 선택과 개별 기업 가치평가는 유지합니다.

1. **섹터·주도주 후보:** ETF·기관 근거 → 섹터 검색·평가 → 수요 회복, 이익 개선, 예상 실적 상향, 3·6개월 시장 대비 강세, 상승 확산, 가격 부담.
2. **가치투자 고득점 기업:** 활성 거래소 전체 목록 → 기업 가치평가 → 기본 60점 이상, 점수 내림차순. 섹터 검색어는 이 표의 모집단을 제한하지 않습니다. 최소 점수는 화면에서 변경할 수 있습니다.

기업명을 펼치면 가치 시나리오, 점수 구성, 출처, 분석일, 가정과 검토 사항이 표시됩니다. 관찰·기관 상세에서는 저장된 원자료를 확인합니다. 표는 각자 50개씩 페이지를 나눕니다. 미분류 기업도 전체 기업 가치평가에는 포함됩니다.

## 실행

```bash
cd investment
DISABLE_SCHEDULER=1 .venv/bin/python -m uvicorn app.main:app --port 8000
```

처음 실행할 때는 가상환경에 `requirements.txt`를 설치합니다. `INVEST_DB`로 데이터베이스 경로를 변경할 수 있습니다. `INVEST_UNIVERSE`의 기업별 가치평가 가정은 계속 사용하지만, 이 파일의 초기 후보 목록으로 전체 시장을 대신하지 않습니다.

시장 선택 → 목록 갱신 → ETF·기관 자료 조회 또는 섹터 검색 → 관찰 자료 수집 순서로 사용합니다. **전체 기업 가치평가**는 검색어와 관계없이 선택 시장의 모든 활성 일반 주식·ADR를 대상으로 합니다. ETF는 기업 DCF로 평가하지 않습니다. 목록은 확보 범위·출처·기준일을 표시하며 국가별 기존 가치투자 요약 표는 제공하지 않습니다.

작업은 종목별 결과·실패 수를 저장하고 취소·서버 재시작 후 재개를 지원합니다. 전체 시장 평가에는 수천 개의 종목 수집이 필요할 수 있습니다. 수집 실패 시 이전 기업 평가를 보존하고 작업에서 실패를 표시합니다. 새로운 정상 수집 결과가 자료 부족 상태라면 과거의 높은 점수 대신 최신 상태를 사용합니다.

```bash
# 현재 확보한 전체 거래소 목록을 평가
.venv/bin/python -m app.pipeline score --markets KR SG US
# 저장된 자료로 정적 보고서 생성, 네트워크 수집 없음
.venv/bin/python -m app.pipeline none --export ../docs/invest/index.html
```

정적 보고서는 관찰 결과를 50개씩 표시하고 저장된 결과 전체를 검색할 수 있습니다. 새 평가·목록 연결은 실행 중인 앱을 사용하세요. 자동 평가의 기본 대상은 KR/SG/US입니다. 다른 시장의 과거 저장 이력은 삭제하지 않습니다.

투자 보고서를 내보낸 뒤 프로젝트 루트에서 `python make_site.py`를 실행하면 `docs/reports/investment_YYYYMMDD.html`로 날짜별 사본을 보관합니다. 초기 화면의 **All reports / 전체 결과**에 AI Investment Ideas와 기존 종목 보고서를 날짜 내림차순으로 함께 표시합니다. 날짜는 보고서 생성 시각을 싱가포르 시간으로 변환한 값이며, 같은 날짜의 재생성은 그날의 사본을 갱신하고 다른 날짜의 기록은 보존합니다. 기존 자동 실행도 같은 화면 생성 단계를 사용하므로 별도 일정 변경 없이 투자 보고서를 보관합니다.

## 점수와 자료 조건

가치 점수는 가치평가 35 / 사업 품질 25 / 재무 20 / 자본배분 10 / 성장 10입니다. 유효한 최신 `value-v1` 평가가 있고 `analyzable`인 활성 기업만 고득점 표에 들어갑니다. 금융·REIT 등 전용 모형 필요, 자료 부족, 검토 보류, 이전 버전 점수는 제외합니다. 점수 필터와 안전마진은 다른 조건이며 음의 안전마진도 숨기지 않습니다.

FCFF/WACC와 FCFE/자기자본비용을 구별하고 같은 연도의 EBIT·세율·감가상각·설비투자·운전자본으로 FCFF를 계산합니다. 완전한 연간 자료가 3개 이상일 때 역사적 중앙값을 초기 정상 현금흐름으로 사용합니다. 보수적·기준·낙관적 가치와 민감도, 역산 DCF를 확인할 수 있습니다. 할인율 10%·영구성장률 2%는 예시 가정이며 회사별 실제 자본비용을 입증하지 않습니다. 정상화·ADR 주식 수·회계 범위·비경상 항목은 추가 검토가 필요합니다.

관찰 점수는 기존 상대강도 40 / 실적 40 / 유동성 20을 유지합니다. 3·6·12개월 조정 상대강도, 동일 기간 실적 변화 최소 2개, 거래대금 순위와 같은 시장·기준일 비교 표본 20개가 필요합니다. 여섯 신호 전체의 종합 점수가 아닙니다. 부족하면 점수는 보류하지만 확보한 원자료는 표시합니다.

3·6개월 상대강도는 `(종목 성장배수 / 비교 ETF 성장배수 - 1) × 100`입니다. 배당·분할 조정 수익률을 사용하고 KR 069500, SG ES3, US SPY와 비교합니다. ETF 비용·추적 오차·시장 대표 범위 차이가 있습니다. 상승 확산은 같은 시장·섹터·관찰일 구성 기업의 시장 대비 강세 비율과 절대 상승 비율이며, 표본 수/분류된 전체 구성 기업 수를 표시합니다. 다른 날짜의 기업을 같은 분모에 넣지 않습니다.

## 목록과 데이터 연결 범위

| 시장 | 목록 | ETF·기관 |
|---|---|---|
| 한국 | KRX KIND 기업 목록. 우선주·ETF를 포함한 모든 증권의 목록은 아님 | KRX 기관 순매수 연결기, 로그인 설정 필요 |
| 미국 | Nasdaq Trader Nasdaq/기타 거래소 목록, 증권 유형 분리 | ETF 보조 자료, SEC 13F와 확인된 CUSIP 연결 |
| 싱가포르 | 자동 전체 목록 연결 미구현. 출처·기준일 있는 SGX 목록 입력 지원 | 출처 있는 자료 입력 지원 |

[SGX 공식 증권 화면](https://www.sgx.com/stock-exchange/securities-prices)을 참고할 수 있습니다. SGX 전체 목록을 실제 확보하기 전에는 미확보/부분 목록으로 표시합니다. 다른 국가의 자동 공급자는 검색·기본 평가 대상에 포함하지 않습니다.

ETF NAV·AUM·거래대금은 설정/환매가 아닙니다. 실제 설정/환매는 `etf_reported_flow`로 입력합니다. NAV·발행좌수·동일 날짜·통화·기업행동 확인 조건을 충족할 때만 `etf_nav`로 설정/환매를 추정합니다. ETF 편입은 기준일과 구성 비중으로 기업에 연결하고 같은 섹터 연결은 별도로 표시합니다. 미국 13F는 분기 보유 변화이며 실제 거래일·순매수 금액을 제공하지 않습니다.

한국·미국 공식 공시는 `DART_API_KEY`, `SEC_USER_AGENT`가 필요합니다. 한국 기관 거래는 별도로 `KRX_ID`, `KRX_PW`가 필요합니다. 로컬 `.env` 또는 실행 환경에 설정하고 서버를 재시작하세요. 키를 채팅에 붙이지 마세요. 공식 공시 수집은 현재 `universe.json`에 설정된 후보에 한정되며 거래소 전체의 공시 검증 완료를 의미하지 않습니다. 일치 기간·통화·회계 범위의 일부 재무 항목 대조와 전체 가치평가 검증을 구별합니다.

## 자료 입력

기관 공시·자료 연결에서 JSON 파일을 선택합니다. 목록은 `market`, `source`, `observed_at`, `complete`, `rows`를 포함합니다. 종목에는 `id`, `market`, `exchange`, `code`, `ticker`, `name`, `type`, `currency`가 필요합니다. 식별자는 `시장:거래소:코드:유형`입니다. `complete:true`는 기존 시장 활성 목록을 대체하므로 전 목록일 때만 사용합니다. 부분 입력은 기존 목록을 보존하고 입력된 종목을 추가합니다.

재고는 Yahoo Finance 재무제표에서 전년 동기 장부금액을 자동 비교합니다. 분기 자료가 비교 가능하지 않으면 연간 자료를 사용하며, 통화와 비교 기간을 표시합니다. 재고 단독 자료는 수요 회복의 부분 근거로 표시하며, 수주·판매량·제품 가격과 이익 전망 수정은 별도의 검증된 출처 자료를 입력할 수 있습니다. 아래 식별자를 현재 목록의 실제 종목 식별자로 바꾸세요. 예시 기업은 자동으로 삽입되지 않습니다.

```json
{
  "listing_id": "SG:SGX:EXAMPLE:stock",
  "kind": "demand",
  "period": "2026-09-30",
  "available_at": "2026-10-01T00:00:00Z",
  "data": {
    "source": "검토한 기업 공시 원문 URL",
    "measurements": [{
      "metric": "orders", "product": "동일 제품", "unit": "개",
      "previous": 100, "current": 120,
      "previous_period": "2025-Q2", "current_period": "2026-Q2"
    }]
  }
}
```

수요 `metric`은 `orders`, `volume`, `inventory`, `product_price`입니다. 같은 제품·단위·비교 기간을 사용합니다. 재고 감소는 개선 방향으로 계산합니다. 매출 증가만으로 수요 회복을 대신하지 않습니다.

```json
{
  "listing_id": "US:NASDAQ:EXAMPLE:stock",
  "kind": "earnings_estimates",
  "period": "2026-09-30",
  "available_at": "2026-10-01T00:00:00Z",
  "data": {
    "source": "검토한 전망 자료 원문 URL",
    "forecast_period": "2027-FY", "currency": "USD",
    "previous": 2, "current": 3,
    "previous_observed_at": "2026-09-01T00:00:00Z"
  }
}
```

전망 대상 기간이 같은 이전·현재 추정치를 사용합니다. `previous_forecast_period`를 지정하면 `forecast_period`와 같아야 합니다. 섹터 상향 비율은 같은 관찰일·전망 대상 기간의 확보 표본 기준입니다. 과거 EPS 성장은 예상 실적 상향을 대신하지 않습니다. 모든 입력 자료의 실제 첫 수집 시점은 시스템 현재 시각이며 과거로 소급하지 않습니다.

## API와 검증

- `GET /api/report?market=KR&query=반도체&min_score=70&observation_offset=0&value_offset=0&limit=50`: 두 독립 결과와 목록 커버리지.
- `GET /api/discovery/search`, `GET /api/discovery/funds`, `GET /api/discovery/detail?listing_id=...`.
- `POST /api/discovery/refresh?market=KR`: 목록 갱신.
- `POST /api/discovery/evaluate-market` + `{"market":"US"}`: 전체 기업 가치평가, 검색어 무관. `null`은 세 시장 전체.
- `POST /api/discovery/evaluate`, `POST /api/discovery/enrich`: 선택 식별자 또는 검색 결과 평가·관찰 수집.
- `GET /api/discovery/jobs/{id}`, `POST /api/discovery/jobs/{id}/cancel`, `POST /api/discovery/jobs/{id}/resume`.
- `POST /api/discovery/import`, `POST /api/discovery/flows/import`.
- `GET /api/stocks`, `GET /api/stocks/{ticker}`, `GET /api/filings/{ticker}`, `GET /api/sources`.
- `POST /api/run?step=official`: 설정된 한국·미국 후보의 공식 공시 수집.

`/api/countries`, `/api/macro`는 삭제되어 404입니다. 삭제된 기능의 과거 저장 데이터는 읽거나 갱신하지 않습니다. 자료 입력은 10MB, 변경 요청은 클라이언트별 분당 30회로 제한합니다.

프로젝트 루트에서 `investment/.venv/bin/python -m pytest -q`로 검증합니다. 계산·API·데이터 격리·작업·집계 테스트는 오프라인 입력을 사용하며 실제 공급자 전체 연결·자료의 정확성·점수의 예측력을 입증하지 않습니다.

### 미확인 자료의 자동 보완

`python -m app.pipeline all`은 보고서 생성 전에 주가·실적 신호를 자동 수집합니다. 한국·싱가포르·미국을 번갈아 처리하며, 미수집/오래된 자료부터 하루 기본 100개를 보완합니다(`INVEST_SIGNAL_BATCH`). 한 회차는 5분의 수집 예산을 사용합니다. 개별 외부 요청이 끝나면 시간을 확인하므로 종료 시간은 더 길어질 수 있습니다. 실패한 종목은 이전 자료를 보존하고 다음 날 다시 시도합니다. 전체 수천 종목의 자료 확보에는 여러 회차가 필요합니다.

`python -m app.pipeline signals --export ../docs/invest/index.html`로 신호만 수집하고 보고서를 갱신할 수 있습니다. 상단에 주가·실적 자료 확보 수와 실패 수를 표시합니다. 재고는 관찰 자료 수집 시 자동 보완합니다. 수주·판매량·제품 가격과 컨센서스 수정 자료는 여전히 별도 출처 연결 또는 입력이 필요하며, 미확인 표시를 임의 값으로 채우지 않습니다.

### ETF·기관 공개 보유 자동 수집

정기 실행(`all`, `score`, `signals`)은 기업 신호 수집 전에 ETF 구성 자료를 수집합니다. 기본 15개/회차(`INVEST_FUND_BATCH`), 3분 예산이며 미수집·오래된 ETF부터 처리합니다. SPY·QQQ·VTI·VOO·SMH·SOXX·섹터 ETF·EWY 등을 초기 우선 대상으로 삼습니다. 전체 ETF의 구성 자료를 확보했다는 의미는 아닙니다. `python -m app.pipeline flows --export ../docs/invest/index.html`로 ETF만 보완할 수 있습니다.

기업 관찰 자료 수집은 Yahoo Finance의 기관 공개 보유 자료도 저장합니다. 기관명·보고일·주식 수·확인 가능한 지분 비율과 출처를 표시합니다. 보조 제공처의 자료로 SEC 13F 원문 검증 또는 기관 순매수를 대신하지 않습니다. 제공처 평가금액의 기준은 검증되지 않아 표시하지 않습니다. 한국 기관 순매수는 기존 KRX 연결이 필요합니다.

ETF 상위 구성종목은 동일한 종목 식별자로 연결하며 해외 상장 ETF의 한국 기업 보유도 표시합니다. 제공처가 한국 거래소 접미사를 잘못 반환하면 한국 활성 일반 주식 목록에서 고유 종목 코드가 정확히 하나 일치하는 경우에만 보정합니다. 기업명 유사도만으로 연결하지 않습니다. ETF 구성 기준일이 제공되지 않으면 수집일과 구별해 '구성 기준일 미확인'으로 표시합니다.


## 자동 실행 범위 (GitHub Actions·스케줄러)

- `catalog` 단계: KR·US·SG 상장 목록이 없거나 7일(`INVEST_CATALOG_DAYS`)보다 오래되면 자동 갱신합니다.
- SG: SGX 증권 목록 연결을 먼저 시도하고, 실패하면 STI 구성 종목 + 설정 후보로 **부분 목록**을 만듭니다(화면에 "부분 목록"으로 표시).
- `score` 단계: 전체 목록을 한 번에 평가하지 않습니다. 실행마다 최대 150개(`INVEST_SCORE_BATCH`), 900초(`INVEST_SCORE_SECONDS`) 안에서
  설정 후보 → 오래된 순서로 순환 평가합니다. 전체 시장이 한 바퀴 도는 데 여러 날이 걸립니다.
- 가치투자 표 기본 최소 점수: 60점.

기업명 아래의 최근 1개월 그래프는 Yahoo Finance의 배당·분할 조정 일별 종가입니다. 마지막 거래일에서 한 달 전 날짜를 기준으로 그날 또는 직전 거래일 종가부터 표시하며 등락률도 동일 기간으로 계산합니다. 신규 상장으로 기간이 부족하면 '기간 부족'을 표시합니다. 가격 자료는 기관·재무 수집 결과와 별개로 보존합니다. 주가 흐름 그래프는 가치평가 후보 표에도 동일하게 표시합니다.

### 공개 투자회사 의견 및 가격 기준

기업 관찰 수집은 Yahoo Finance가 제공하는 최근 180일의 투자회사별 의견 변경(최대 10건), 확인 가능한 이전/신규 목표가, 현재가, 컨센서스 목표가 평균·상하단·분석가 수를 저장합니다. 의견 날짜와 수집 시점을 구분하며 개별 목표가가 없으면 평균 목표가로 대신 채우지 않습니다. 이 자료는 공개 의견의 보조 제공처 요약으로, 개별 리포트 원문·논거를 자동 분석한 결과가 아닙니다. 한국·싱가포르 일부 종목은 의견 자료가 지원되지 않습니다.

기업명 아래에 현재가, 매수 검토가, 매도 검토가를 표시합니다. 기준 시나리오의 내재가치가 계산되고 표시 통화가 일치할 때에만 매수 검토가 = 내재가치 × 80%(안전마진 20%), 매도 검토가 = 기준 내재가치로 계산합니다. ADR/특수 업종 등 계산 보류 종목에는 임의 가격을 넣지 않습니다. 이 값은 기존 가치평가의 가정에 따른 검토 기준이며 예상 체결가·주문·보장된 미래 가격이 아닙니다. 컨센서스 목표가와 가치평가 계산 가격은 구별합니다.

`research_sources.json`은 확인 가능한 공개 원문 링크를 종목에 연결합니다. 초기 연결은 DBS의 애플·엔비디아 과거 리포트와 미래에셋증권 삼성전자 자료이며 발행일이 미확인인 자료는 그렇게 표시합니다. 과거 원문을 현재 목표가 산정에 쓰지 않으며 자동으로 최신 리포트를 발견하는 범용 수집기는 아직 아닙니다.

표시 가격 하한은 한국 5,000 KRW, 싱가포르 1 SGD, 미국 5 USD입니다. 하한과 같은 가격은 포함합니다. 조정 차트 가격이 아닌 제공 현재가 또는 저장된 가치평가 가격으로 비교하며, 통화·가격 미확인 기업은 결과에서 제외합니다. 제외 종목도 원래 목록과 수집 대상에서 삭제하지 않습니다.
정적 보고서에서도 저장된 가격 하한 충족 종목 전체를 검색하고 50개씩 페이지를 이동할 수 있습니다. 기업명 검색은 같은 시장의 확인된 업종 분류를 공유하는 관련 기업을 포함합니다.

### 뉴스 근거 후보 (독립 목록)

기존 섹터·주도주 후보와 가치투자 점수는 유지하며 두 분석 흐름 아래에 별도의 뉴스 검토 목록을 표시합니다. 최근 14일의 저장 기사 중 기업명이 제목에 직접 연결되고 수주·전망 상향·수요 증가·승인·사업 확대·주주환원 키워드가 있는 기사를 발굴합니다. 취소·부인·루머 등 주의 문구, 미래 날짜, 중복 제목을 제외하고 최대 30건을 표시합니다. 기존 가격 하한과 확인 가능한 통화를 적용합니다. 기사 링크·출처·발행일·발굴 유형·연결 기준을 제공합니다.

키워드 기반 후보이며 기사 원문 전체, 실제 수혜 규모 또는 공식 공시와의 일치를 자동 검증한 결과는 아닙니다. 모든 후보는 '원문·공시 확인 필요'로 표시하고 투자 점수·가치평가·매매 검토 가격을 변경하지 않습니다. 정기 뉴스 수집 후 보고서 생성 시 저장된 최신 기사로 갱신합니다.
